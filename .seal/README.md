# Research flow kernel

Reusable assembly of existing practices (OSF prereg, Spec Kit loop, BMAD units, OpenSpec explore/archive). Not a new framework.

**Extract later:** copy this `.seal/` folder into another project; instantiate `templates/` into a study directory (`studies/<slug>/` or, in this repo, `scendo/`).

| File | Role |
|---|---|
| `constitution.md` | Non-negotiable rules |
| `E2E_FLOW.md` | End-to-end sequence |
| `workflows.md` | Chat commands |
| `agents.md` | Personas |
| `SOURCES.md` | What we adopted (BMAD, OpenSpec, Spec Kit, OSF) |
| `templates/` | Blank study artifacts |

The **public** lock for any study is an [OSF secondary-data preregistration](https://osf.io/gvcs) (or equivalent), not this folder’s nickname.
