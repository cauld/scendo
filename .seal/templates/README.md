# Instantiate a study

1. Copy this `templates/` set into a study directory (`studies/<slug>/`, or `scendo/` in this repo).
2. Follow [`.seal/E2E_FLOW.md`](../E2E_FLOW.md). Fill `QUESTION`, `CLAIMS`, `KILL`, `PROTOCOL`.
3. Keep `.seal/` unchanged except constitution updates that apply to *every* future study.
4. Study-specific unit tables live in that study’s `PHASES.md` and `units/`.
